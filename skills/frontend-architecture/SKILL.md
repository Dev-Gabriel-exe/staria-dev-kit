# Arquitetura de frontend

1. Identify the user flow, target devices, framework and constraints before selecting libraries.
2. Map pages, design tokens, data fetching, state and component boundaries. Use semantic HTML as the baseline.
3. Pick at most one primary UI kit and one primary motion library initially; avoid incompatible duplicates.
4. For interface inspiration, consult `references/catalogo-frontend.md` and shortlist by use-case, licensing and price.
5. Implement a minimal vertical slice, then verify mobile, accessibility and production build.
6. Deliver files, run instructions, screenshots or tested URLs, with known limitations.
**Do not** assume external catalog services are free today; re-check before sign-up.
