# Web 3D e experiências imersivas

1. Confirm that 3D serves the product goal and that a static/2D fallback is acceptable.
2. Select Three.js/WebGL only for real 3D interaction; prefer video or images for cinematic backgrounds when simpler.
3. Model rendering cost: triangles, textures, device pixel ratio, loading and battery use.
4. Use lazy loading, camera limits and cleanup of listeners and GPU resources.
5. Test WebGL absence, mobile GPU, touch interactions and reduced-motion.
6. Consult the catalog for Three.js, inspiration and asset sources, checking licenses individually.
