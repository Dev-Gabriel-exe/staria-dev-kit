# Componentes reutilizáveis

1. Define component responsibility, props, loading, empty, error and interaction states.
2. Prefer semantic structure, keyboard controls, controlled inputs when needed, and typed public props.
3. Adapt a visual pattern from the frontend reference catalog rather than copying a site's identity.
4. Verify responsive behavior at narrow, tablet and desktop widths and guard against horizontal overflow.
5. Add unit/component tests for state transitions and edge cases.
6. Supply a small usage example, not just a raw isolated snippet.
