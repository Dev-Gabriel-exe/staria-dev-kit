# Integrações e bibliotecas complementares

**Estas integrações são externas.** O plugin StarIA Dev Kit não as incorpora, não substitui autenticação e não fornece permissões automaticamente. Consulte a conexão vigente no ChatGPT.

- Superpowers: planejamento, desenvolvimento guiado por testes, revisão e depuração.
- Product Design: pesquisa de UX, protótipos, interface e auditoria.
- Figma: design de interfaces, bibliotecas, componentes e design-to-code.
- Vercel: apps, APIs, autenticação, storage, deploy e automações.
- Neon: PostgreSQL, branches e queries.
- Redis: dados, cache, pesquisa e memória quando fizer sentido.
- GitHub: código, issues, PRs e CI.
- Plugin Creator: atualiza este conjunto de skills; mudanças requerem salvar nova versão.

**Não converter links do catálogo em supostas skills instaladas.** Não instalar serviços com cobrança nem aceitar trials automaticamente. A ausência de MCP próprio neste plugin significa que ele usa apenas skills e ferramentas já disponíveis no ChatGPT.
