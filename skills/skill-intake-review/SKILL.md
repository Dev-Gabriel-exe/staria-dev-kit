# Curadoria e integração de skills

1. Record source URL, author, license, revision, purpose and required tools for each candidate.
2. Read SKILL.md, scripts, dependencies and referenced files; check for secrets, exfiltration, execution, hidden paid APIs and privileged operations.
3. Distinguish a reusable instruction skill from an external plugin/MCP connector or a webpage component catalog.
4. For personal use, package original metadata and safe adaptation; never silently copy entire third-party repos or claim redistribution rights.
5. Prefer linking to existing installed Superpowers, Product Design, Figma, Vercel, Neon, Redis and GitHub capabilities rather than duplicating them.
6. Run trigger and representative use-case tests, then version the private plugin and document what was added; recheck terms before any future public distribution.
