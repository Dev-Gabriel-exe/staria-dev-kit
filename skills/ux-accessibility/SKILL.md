# UX, acessibilidade e responsividade

1. Identify one primary user task and its success criteria.
2. Build semantic headings, forms, status messages and navigation order.
3. Ensure visible focus, keyboard interaction, sufficient contrast, helpful validation and labels.
4. Respect prefers-reduced-motion and avoid autoplay that blocks tasks.
5. Review mobile tap targets, overflow, latency and error recovery.
6. Report concrete defects and verify after changes; no unsupported claims of WCAG certification.
