# Contributing / Como contribuir

Obrigado pelo interesse no StarIA Dev Kit!

1. Abra uma Issue explicando o problema ou a melhoria, com uma reprodução mínima.
2. Para mudanças de código, envie um Pull Request pequeno, mantendo as 18 skills existentes e testes relevantes.
3. Execute `python -m unittest discover -s tests -v` e informe as limitações da verificação.
4. Não inclua credenciais, código de clientes, dados pessoais ou ferramentas terceirizadas não licenciadas.
5. Não anuncie o Debug Gate como sandbox de segurança ou como bloqueio infalível: hooks dependem do executor.

**License:** not selected yet; public visibility does not grant an open-source license. Discuss redistribution and contributor licensing before submitting substantive code.
